# ECE366-Project_2
We are designing a program that checks if the n'th Fibonacci number is an odd number. This is broken up into parts, where first we calculate the n'th Fibonacci number, and then determine whether that value is odd or not. The program will return '1' if the n'th Fibonacci number is odd, and '0' otherwise.

### How to Run the Program
Our MIPS file can be run using the Mars simulator by first assembling the program and then executing it, either step by step or all at once. Our implementation prompts the user to input a specific value for n, and then the n'th number in the Fibonacci sequence gets returned based on the calculation from the given pseudocode. The output also gets printed to the terminal once the calculation is complete. For the isOdd() function, the program will be called by the main program and checks whether the given argument is odd or not. The output register gets set to 0 or 1 depending on whether the passed argument is odd or not. Note: the program argument gets passed through the $a0 register, and the output is returned through the $v0 register. For our complete MIPS program, we have integrated those 2 functions together. At the start of the program, we have the n value stored in memory, which gets passed to the Fibonacci function to calculate the n'th number in the Fibonacci sequence. This returned value then gets passed to the isOdd() function, which uses division by repeated subtraction to determine whether the n'th Fibonacci number is odd or not. If the number is odd the function returns a 1 for "True", and if the number is even the function returns a 0 for "False." This returned boolean value finally gets printed to the terminal.
